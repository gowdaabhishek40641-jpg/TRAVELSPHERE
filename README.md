# 🌍 TravelSphere

TravelSphere is a modern travel-planning website designed to help users explore destinations and begin planning their journeys.

## 🎨 Card Interaction

When the user moves the mouse over a destination card:

```text
Card
 ↓
Moves upward
 ↓
Slightly enlarges
 ↓
Shadow becomes stronger
 ↓
Border becomes visible
 ↓
Destination emoji enlarges
 ↓
Emoji rotates
 ↓
Image overlay appears
 ↓
Title changes color
 ↓
View Trip appears
```
